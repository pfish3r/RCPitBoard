# RCPitBoard

Standalone React/Vite frontend and Node.js server. The original export has been adapted to run without Base44.

- Read README.md for installation, runtime settings and updates.
- Keep the race-day interface and LiveRC parsing behaviour unless asked to change them.
- Keep .env, saved settings, tokens and credentials out of Git.
- Run npm test and npm run build for application changes.
- Use bash -n scripts/setup.sh scripts/update.sh for deployment script changes.
- Docker Compose is the supported Debian deployment path.
